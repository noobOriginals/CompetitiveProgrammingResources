## Competitive Programming

This is a repo that contains all algorithm examples I've written over time, along with every solution to programming tasks that I've solved in the past.  

- **Programming Language**: Any code from this repository is C/C++.
- **Explanations**: Some of the code has comments that explain (to my best ability) what the code does, but I don't guarantee that for every file.
- **Solutions**: Each solution file has a comment with a link to the source of the problem on it's first line.
- **Scripts**: The present scripts in this repo are used to create the necessary files for whenever a solve has to be uploaded, along with running the code of any example file.
